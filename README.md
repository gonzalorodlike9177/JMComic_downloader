## ❓ Troubleshooting Common Issues

### The Program Won't Start

- Make sure you extracted the ZIP file completely before running
- Try right-clicking the EXE and selecting **"Run as administrator"**
- Check that your antivirus isn't blocking it (add an exception if needed)

### Downloads Are Slow

- Reduce the number of threads in Settings
- Check your internet connection
- Try downloading during off-peak hours

### I Get an Error About Missing Files

- Re-download the ZIP file — it may have been corrupted during download
- Make sure you have enough free disk space
